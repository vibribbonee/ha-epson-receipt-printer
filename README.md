# Epson ESC/POS Receipt Printer

Print receipts, shopping lists, barcodes, and QR codes on a networked ESC/POS printer.

## Setup

Install the integration through HACS as a custom **Integration** repository when using a public copy, or copy `custom_components/epson_receipt_printer` into Home Assistant’s `custom_components` directory. Restart Home Assistant, then open **Settings → Devices & services → Add integration**. Choose Epson ESC/POS Receipt Printer and enter the printer address and port.

For an upgrade, keep the existing integration entry so Home Assistant retains its configuration.

See the [printer examples and service documentation](https://github.com/vibribbonee/home-assistant-printers) for automation examples.
